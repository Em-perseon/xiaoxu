绿色机器人是 Actor，负责选择输出；戴眼镜的是 Critic，负责预测未来回报。评分来自独立的评判器。三轮回答是预设的教学样例，不是随机采样，也不代表下一轮一定答对；但每轮的策略概率和价值预估都继承上一轮的更新。这里固定 γ = 1，初始价值为 0.2、0.5、0.8。光点表示训练信号，不表示梯度穿过环境。

Actor 更新镜头放大最后一个位置：相同问题与前缀“答案是”下，只保留候选 4 和 5，二者概率之和始终为 100%。采样动作的优势 A = G − V旧；固定优势后，按 z新 = z旧 + 0.5A(1−p旧)、p新 = sigmoid(z新) 更新。优势不是直接加到概率上的百分点。选中 5 时，用它自己的概率计算梯度，再取补数得到 4 的概率。Critic 按 V新 = V旧 + 0.5(G−V旧) 更新。

前两个位置也进行独立的二选一策略更新，动画只放大最后一处。真实 LLM 使用全词表且共享参数，其他候选不一定都同向变化；PPO 还涉及 GAE、概率比与裁剪。token 为示意划分，优势不能证明动作的因果贡献。

为什么 Critic 要这样调整？

Critic 要降低预估与实际回报的平方误差：L = ½(V − G)²。对这里独立的标量 V 求导，梯度为 V − G。沿梯度的反方向更新，得到 V新 = V旧 − α(V旧 − G) = V旧 + α(G − V旧)。因此估高了就调低，估低了就调高。

例如旧预估 0.60，实际回报 0，学习率 0.5：V新 = 0.60 + 0.5 × (0 − 0.60) = 0.30。平方损失从 0.18 降到 0.045。这里选择 0.5 只是为了演示“修正一半差距”，不是固定的算法要求。

每一行对应生成一个 token 之前的状态，包含原问题和已经生成的前缀；Critic 预测从该状态开始的未来回报，而不是给单个 token 打分。真实神经网络更新的是参数 φ：φ新 = φ旧 − α∇φ L；重新前向计算得到的新 V 不一定恰好移动一半。

为什么 Actor 的概率会这样变化？

目标不是模仿某个固定答案，而是提高期望回报 J(θ) = E[R]。策略梯度用采样得到的优势估计更新方向：∇θ J ≈ A ∇θ log πθ(a|s)。状态价值作为与当前动作无关的基线，用来减少梯度估计的方差。实现时最小化 L = −A log πθ(a|s)，并把本轮算好的 A 当作常数，不沿 A 更新 Actor。

A 为正时，提高已采样动作的概率会降低这项损失；A 为负时，降低概率会降低损失。这是一次采样提供的学习信号，不证明该动作本身造成了成功，也不保证每次更新都提高真实任务表现。决定方向的是优势，不是仅看答案对错。

本动画是独立二选一策略：p = sigmoid(z)，z = ln[p/(1−p)] 是已采样动作相对另一个候选的倾向分数。由 ∂L/∂z = −A(1−p)，梯度下降得到 z新 = z旧 + αA(1−p旧)，然后计算 p新 = sigmoid(z新)。例如 p旧 = 0.20、A = 0.20、α = 0.5：z 从 −1.386 增加 0.080 到 −1.306，p 从 20.0% 变为约 21.3%，不是直接增加 20 个百分点。

真实 LLM 更新网络参数：θ新 = θ旧 + αA∇θ log πθ(a|s)，再重新计算全词表概率；并不是直接修改一个独立的 z。这里演示基础策略梯度，不是完整 PPO，未包含概率比裁剪等约束。
